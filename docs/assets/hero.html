Anamnesia

Long-term memory for Claude Code that forgets on purpose
It doesn't keep your transcripts. Every session is read once, the few things still worth knowing next month are extracted, and the rest is thrown away. One binary, one Postgres container, nothing leaves your machine.

One binary

The CLI, the Claude Code hooks and the memory server are the same executable, so they can never end up on different versions. It starts its own Postgres — no compose file, no image to build.
